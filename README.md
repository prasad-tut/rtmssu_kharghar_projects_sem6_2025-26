# Microservices Project Collection
**Developed by: Suyash Vishwas Jadhav**

This repository contains two distinct microservice-based ticket management systems, ranging from a basic architectural setup to a highly advanced implementation.

---

## Project Structure

### 1. [Basic Microservice App](./Basic_Microservice_app)
A fundamental implementation of microservices architecture focused on core connectivity and service discovery.

**Key Features:**
- **Service Integration**: User service can view Ticket and Ticket service can view User details.


### 2. [Advance Microservices App](./Advnace_Micorservices_app)
A production-ready, highly sophisticated ticket management ecosystem with advanced features and real-time capabilities.

**Key Features:**
- **Enterprise Services**: Auth, Admin, Customer, and Executive services.
- **Real-time Engine**: Live chat between customers and support executives.
- **AI Integration**: Intelligent reply suggestions for executives to improve response times.
- **Complex Workflows**: Ticket resolution flows, customer ratings, and comprehensive analytics.
- **Technology**: PostgreSQL, ngrok integration, Spring Boot, and complex inter-service communication.
